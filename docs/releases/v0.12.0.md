# Kurator 0.12.0 – textured 3D, lights, 2D lit preview, SVG sizes, engine projects

3D models now show their textures, and the viewer gets lights and map views. 2D art with normal,
glow and depth maps can be previewed lit. Several indexing errors are fixed, and Kurator stays
out of the way inside game projects and code repositories.

## Highlights

### 3D: textures, lights, map views
- **Textured viewer:** glTF/GLB, OBJ and FBX models show their base colour, normal, emissive,
  occlusion and metal/roughness maps. Embedded textures work too: GLB images and FBX video content.
- **Views:** *Lit*, *Base colour*, *Clay* (no textures), *Normals* and *UV checker*. Click a map in
  the list to see only that map on the model.
- **Lights:** Studio, Sun and sky, Rim light, Headlight and Soft. **Alt+drag** turns the lights,
  **L** switches to the next preset. *Smooth* shading uses the normals stored in the file.
  *DirectX normals* flips the green channel of normal maps made for DirectX/Unreal.
- **Thumbnails** are now textured, so textured game assets no longer turn out grey or a single
  average colour.
- **Texture detection:** the side panel lists every map a model uses, with missing ones in red.
  Textures saved with a path from another computer, or with another extension, are found by name
  next to the model and in `textures/`, `maps/` and `materials/` folders.
- **Look ▾ → 3D models** filters models *with textures*, *without textures*, or *with textures
  missing on disk*.

### 2D art with companion maps
- Kurator recognises companion maps named after a picture: `hero.png` with `hero_normal`,
  `_glow`, `_ao`, `_depth`, `_specular`, `_sky`/`_bg` and similar suffixes. It checks the
  picture's proportions and never mistakes version names like `_v2` or `_final` for maps.
- **☀ Lit** in the viewer (or **L**):
  - a point light follows the mouse and the normal map shapes it;
  - glow maps shine with a soft halo;
  - AO darkens the ambient light;
  - the depth map gives a parallax shift (and lighting, when there is no normal map);
  - a background layer sits behind the picture.
- Sliders set light height, reach, ambient, glow and parallax, and tabs show each map on its own.
- In the side panel, **2D maps** lists the maps, and **▤ stack maps** shows only the picture in the
  grid with its maps stacked under it.

## Fixes
- **Memory errors on big GLB files** ("Unable to allocate 3.81 MiB…"):
  - Every core was rendering a big model at once, which exhausted the memory.
  - Big files now take turns: 2–3 at a time, set with `KURATOR_HEAVY_JOBS`.
  - The renderer uses less memory and falls back to fewer triangles.
  - Files that hit a memory error are tried again on the next scan.
- **`.obj` files that are compiled code** (from Visual Studio and other compilers): they used to
  fail with `invalid literal for int()`. They now show as *program code, not 3D*. Damaged lines in
  real OBJ files are skipped instead of failing the whole file.
- **Inkscape SVGs with "SVG has an invalid size":** the cause was the SVG renderer reading sizes in
  mm/cm/in/pt as zero. They now render. Drawings whose page has no size show their whole content.
- **New setting, ⚙ Settings → SVG: show all objects:** grows the page to take in objects lying
  outside it, in both previews and the viewer.

## Game projects and code repositories
- Kurator never writes thumbnails or caches into library folders. Everything lives in its data
  folder, so adding a Unity/Godot/Unreal project or a git repository leaves it untouched.
- Generated folders are no longer indexed, and live updates ignore them:
  - Unity: `Library`, `Temp`, `Logs`, `obj`, `Build`.
  - Unreal: `Intermediate`, `Saved`, `DerivedDataCache`, `Binaries`.
  - Build output next to `.sln`/`.csproj`/CMake/Cargo projects.
  - Python virtual environments.
- Moving an asset takes its Unity `.meta` file (its GUID) and its Godot `.import`/`.uid` files
  along, so references in scenes keep working. Undo brings them back.
- Optional XMP sidecars are not written inside engine projects or git repositories.

## Upgrading
- Run `update.bat` / `./update.sh`. No catalog changes are needed.
- On the first start, files that failed to index before (for example the SVGs and GLBs above) are
  tried again. **3D models are read once more in the background**, which gives them textured
  thumbnails and the texture lists for the filter. Large model collections take a while; the grid
  stays usable.
