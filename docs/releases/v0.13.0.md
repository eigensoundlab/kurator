# Kurator 0.13.0 – compressed glTF, binary USD, turntables, sound regions, Godot resources

More 3D files can be read. Thumbnails turn under the mouse. Parts of sounds can be cut out as new
files. Sprite sheets can go straight into Godot.

## Highlights

### Compressed glTF and binary USD
- **Meshopt** (`EXT_meshopt_compression`, written by gltfpack and glTF-Transform) is decoded by
  Kurator itself, in Python. The decoder is checked against the test vectors of meshoptimizer.
- **Draco** (`KHR_draco_mesh_compression`) and **binary USD** (`.usd`, `.usdc`, and USDZ files
  holding binary USD) need the new optional **3D add-on**: `install.bat 3d` / `./install.sh 3d`
  (DracoPy and Pixar's usd-core, about 60 MB).
- USD files bring their transforms, texture coordinates and UsdPreviewSurface materials. Textures
  are found next to the file or inside the USDZ package.
- Without the add-on these files are listed with a note saying what to install.

### Turntable on hover
- Move the mouse across a 3D thumbnail and the model turns. Kurator renders 12 views while it
  indexes the model.
- It uses the *▶ Hover* switch, like video scrubbing.

### Cut a region out of a sound
- In the full-size waveform view, **drag** to select a region. Shift+click moves its nearer edge.
- The selection bar can:
  - play the selection (**Space**);
  - loop it;
  - zoom to it;
  - **save it as a new file** (**E**).
- Formats: WAV 16/24/32-bit float, FLAC, Ogg Vorbis, MP3, or the format of the original.
- Short equal-power fades avoid clicks, and the level can be normalised to a peak. New files never
  overwrite existing ones, and the original stays untouched.

### Godot 4 resources from sprite sheets and atlases
- **J → Sprites / atlas → Godot 4 resources** writes Godot `.tres` files next to the PNG and JSON:
  - a *SpriteFrames* resource with the animations, for AnimatedSprite2D, at the frame rate you set;
  - for atlases, one *AtlasTexture* per sprite, including trim margins.
- Saved inside a Godot project, the paths are `res://` paths.

## Improvements
- **Previews of very dense models** are simplified by vertex clustering. The surface stays closed,
  where skipping triangles used to leave holes.
- The CI now installs the 3D add-on, so Draco and USD reading are tested on Windows, macOS and
  Linux.

## Safety
- DracoPy and usd-core are native code. They run in a short-lived separate Python process
  (`-I`, with a time limit), so a malformed file can only end that process, never Kurator.
- Both packages were checked with pip-audit: no known vulnerabilities.

## Upgrading
- Run `update.bat` / `./update.sh`. If you want Draco and binary USD, add the add-on:
  `update.bat 3d` / `./update.sh 3d`. Later updates keep it.
- On the first start, 3D models are read once more in the background to make their turntables.
