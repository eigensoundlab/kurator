# Kurator 0.6.0 – file types, sounds and local AI tagging

Kurator now handles far more than pictures: vector files, PDFs, art-app documents and sound files
sit in the same fast grid, and an optional AI add-on, which runs entirely on your own computer,
can search your library by description and suggest tags from a list you choose.

## Highlights

### Type filter and many new formats
- **All types ▾** in the toolbar: every supported extension in groups (Images, Work files, Vector,
  Documents, Game textures, Audio) with checkboxes and presets such as *Finished images*
  (JPG/PNG/WebP only). The choice is remembered.
- **New previews:**
  - **Images:** HEIC/HEIF (decode only), JPEG 2000, QOI, ICO/ICNS, PCX, SGI, PPM and related formats.
  - **Work files:** PSD, Procreate, Clip Studio Paint (`.clip`), with canvas size.
  - **Vector:** SVG/SVGZ (shown sandboxed), Illustrator `.ai`, EPS (embedded preview, Ghostscript
    if installed), CorelDRAW `.cdr` (embedded thumbnail).
  - **Documents:** PDF (first page), InDesign `.indd` (embedded thumbnail).
- **Everything else** (Affinity, GIMP, SAI, Figma, Sketch, XD…) is catalogued too and shows the
  thumbnail Windows has for it, or a neutral card.

### Sound files
- Waveform thumbnails with the length, a player in the side panel, **Space** to play, **P** for
  auto-play while moving with the arrow keys.
- Metadata: length, sample rate, channels, bit depth, peak and RMS level, ID3/Vorbis/MP4 tags,
  **Broadcast WAV** (bext) and **iXML**, UCS category from the file name. The BWF origination date
  becomes the file's date.
- WAV, MP3, OGG, Opus, FLAC, M4A/AAC play in the app; AIFF, CAF, W64, RF64 and WMA are catalogued
  and open in your audio editor.

### AI tagging and search (optional, local)
- Install with `install.bat ai` / `./install.sh ai`. On Windows with an NVIDIA card the installer
  sets up GPU-enabled PyTorch and checks that the GPU works.
- **Search by description:** type `?pencil sketch of a dragon` in the search box.
- **Find similar:** press **S** on an image.
- **Tag pools:** choose the tags the AI may pick from (e.g. *human / robot / creature / icon*). It
  never invents other tags. Three methods:
  - **Image–text model** (SigLIP 2): works right away, no examples needed.
  - **Learn from my tags:** trains on images you have already tagged and reports its accuracy.
  - **Gemma via Ollama:** a fixed answer list, and optional captions for training datasets.
- **Review queue:** suggestions show as hollow dots until you accept (**A**) or reject
  (**Shift+A**) them. Rejections are remembered and teach the trained pools.
- Nothing is uploaded. Model weights download once from Hugging Face on first use.

## Upgrading
- **Requires Python 3.11 or newer** (3.12+ recommended). Python 3.10 reached its end of life in
  October 2026 and the current web framework (Starlette) no longer supports it.
- Unzip over your installation (or `git pull`) and run `update.bat` / `./update.sh`. The catalog
  is migrated automatically; nothing is re-indexed.
- New dependencies, all permissively licensed: numpy, pypdfium2, resvg-py, pi-heif, soundfile,
  tinytag. There is no GPL code.

## Also in this release
- `update.bat ai` keeps the AI add-on when updating. The security check in CI now covers the AI
  packages too.
- Clearer messages when the AI add-on isn't installed.

## Known limitations
- Reading M4A/AAC/WMA waveforms needs `ffmpeg` on the PATH.
- Tested on Linux and in CI on Windows/macOS. The Windows thumbnail fallback and GPU setup have not
  yet been tested on many machines; reports are welcome.
