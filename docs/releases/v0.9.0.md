# Kurator 0.9.0 – from library to game: export, texture sets, duplicates

Projects can now be exported straight into a Unity, Godot or Unreal folder, with each model bringing
its textures. Identical files are found, and backups store them only once. Saved views keep your
favourite filters one click away.

## Highlights

### Export a project to your game
- **Export…** on an open project copies its files into a game project in the **Unity**, **Godot**
  or **Unreal** layout, or simply sorted by type.
- **Models bring their textures and materials** at the same relative paths: OBJ `.mtl` files and
  their maps, glTF buffers and images, textures named in FBX/3DS/DAE files, and a texture set named
  like the model. So models import with their textures.
- Preview first; then only new or changed files are copied on later runs. A `kurator_export.json`
  records where every file came from. Nothing in your library is moved.

### Texture sets
- `rock_albedo.png`, `rock_normal_4k.png`, `rock_roughness.png`… are recognised as one set. The side
  panel shows the set, the files a model uses, and the models that use a texture. Click to jump.

### Duplicates
- **Duplicates** in the sidebar lists files whose exact content is in more than one place, side by
  side. The side panel shows *Also in* with the other locations.
- **Backups store identical files once**; the other copies point to it, and a restore puts the file
  back in every folder. If one copy is edited later, it gets its own backup and the others stay
  safe. On by default (*Store identical files once* in the backup set).

### Saved views
- **☆ Save view** in the path bar keeps the current project, folder, tags, file types, search and
  sort under a name in the sidebar.

### 3D and sound
- **Blender files in 3D:** with Blender installed, Enter on a `.blend` file converts it once to glTF
  in the background and opens it in the 3D viewer. Blender runs with scripts switched off
  (`--disable-autoexec`).
- **Loading progress** for big models, and a **← Back** button (or Esc) in the viewer.
- **Long sounds** (30 s and more: music, ambiences) get **orange** waveforms; short effects stay blue.
  Existing long sounds are redrawn once, automatically.

## Also in this release
- The update/install check no longer prints *"kurator … could not be audited"*: Kurator audits all
  installed packages except itself (it isn't on PyPI), CUDA builds of PyTorch included.

## Upgrading
- `update.bat` / `./update.sh` (or unzip over your installation, then run it). The catalog is
  migrated automatically (backup sets get the new option, saved views get a table).
- Optional: install **Blender** to open `.blend` files in 3D.
