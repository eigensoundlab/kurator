# Kurator 0.7.0 – 3D models, quicker quitting, smoother sorting

3D models join images and sounds: Kurator draws its own previews of common 3D formats, shows
Blender's saved thumbnails, and opens models in a live 3D view, with no 3D software needed. Sorting
into projects is quicker, and Kurator now quits immediately.

## Highlights

### 3D models
- **Rendered previews** for glTF/GLB, OBJ, FBX (binary and ASCII), STL, PLY, COLLADA (`.dae`),
  3MF, 3DS, OFF, USDA/USDZ and MagicaVoxel `.vox`, in the materials' colours (glTF base colours and
  embedded textures, OBJ `.mtl`, vertex colours, voxel palettes).
- **Blender** `.blend` files show the thumbnail Blender saved, including zstd/gzip-compressed files,
  Blender 5.x files and `.blend1` backups, with counts of objects, meshes and materials.
- **Embedded thumbnails** from 3MF (slicers, CAD) and SketchUp. Maya, 3ds Max, Cinema 4D, ZBrush,
  Alembic, Rhino and Substance files show the Windows thumbnail when the application is installed.
- **3D viewer:** Enter or double-click opens a live WebGL view. Drag to turn, right-drag to move,
  use the wheel to zoom and press **0** to reset.
- **Side panel:** triangles, vertices, dimensions and units, meshes, materials, animations, the
  application that wrote the file, and the texture files the model uses. FBX, COLLADA and 3MF
  creation dates count as the file's date.
- New **3D models** group in the type filter.

### Sorting and projects
- **Clear filter rules:**
  - Click a tag or project to see everything with it in the whole library.
  - **Ctrl+click** a tag to narrow the current view (e.g. a project within one folder).
  - **Alt+click** a tag to hide items with it (e.g. everything not yet in *Game A*).
- **Drag** selected images onto a project or tag in the sidebar or the tag bar to add it.
- **− Remove N from Game A** in the path bar while viewing a project. Ctrl+Z undoes it.

### Sounds
- Sounds play when you click them or move onto them with the arrow keys, like in sound-library
  apps. The **♪ Auto-play** switch in the status bar (or **P**) turns this off.
- **▶ on a waveform** plays or stops it without changing the selection, and the playing sound is
  highlighted.

### Quitting
- Closing Kurator (Ctrl+C in its window) used to wait for indexing to finish, which could take
  minutes on a big library. It now stops in about a second. Finished work is saved and the rest
  continues at the next start.

## Also in this release
- The 3D viewer and image viewer share the same keys (← → for the next file, Esc to close).
- The placeholder card no longer cuts off long extensions such as AFPHOTO.
- Sounds the browser can't play (AIFF, CAF…) no longer show a ▶ that does nothing.

## Upgrading
- Unzip over your installation (or `git pull`) and run `update.bat` / `./update.sh`.
- New dependency: **zstandard** (BSD) for compressed Blender files on Python 3.11–3.13; Python 3.14+
  has this built in.

## Known limitations
- Draco- or meshopt-compressed glTF and binary USD (`.usdc`) can't be read yet; they are listed
  with a card or the Windows thumbnail.
- Very large meshes (over 3 million triangles) are thinned out for the preview; the first preview
  of a million-triangle model takes a few seconds.
- The 3D readers were tested with generated files in every format. Files from your own tools that
  don't preview correctly are very welcome as bug reports.
