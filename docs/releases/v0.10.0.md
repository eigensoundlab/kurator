# Kurator 0.10.0 – similar images, version stacks, compare, join and contact sheets

Tools for sorting through many versions and near-copies of your work, and for putting images
together.

## Highlights

### Similar images
- **Similar images** in the sidebar groups pictures that look nearly the same: resized, re-saved as
  JPEG, slightly edited, exported twice. Pick *nearly identical*, *very similar* or *similar*.
- It works inside the current folder, project and filters, and stays fast on large libraries. For
  an existing catalog, the picture fingerprints are made from the thumbnails the first time you open
  the view.

### Version stacks
- **Ctrl+G** stacks the selected versions (sketch → lineart → colour): the grid shows one item, the
  newest on top, with **▤** and the number of versions.
- **Stack by name** finds versions in the selection by their names (`hero_sketch`, `hero_lineart`,
  `hero_v2`, `hero (1)`, `hero copy`…).
- Click ▤ to see all versions. In the side panel, jump between versions or *put on top* another one.
  **Ctrl+Shift+G** unstacks, and the *Stacks* button in the toolbar shows all files again.

### Compare
- Select 2–4 images and press **C**. Zoom and pan move all of them together, so the same detail stays
  lined up. **S** switches two images to a swipe view with a divider that follows the mouse.

### Join images and contact sheets
- **J** (or *Join / sheet…*):
  - **Join** the selection side by side, stacked or in a grid, scaled to one height or width, with a
    gap, a background (or transparent) and an optional result size.
  - **Contact sheet:** pick a page size (A4/A3/A5/Letter/Tabloid or pixels), columns, captions (name,
    date or tags), a title and page numbers. Save as one PDF or as image pages.
- A live preview comes first, and saving never overwrites existing files.

## Fixes
- The test suite now passes on macOS and Windows. The failures were case-insensitive `textures`
  folders being counted twice, and path separators in the tests.
- Blender conversion passes its export script as a file. Long commands with line breaks are
  unreliable on Windows.

## Upgrading
- `update.bat` / `./update.sh`. The catalog is migrated automatically: files get a fingerprint and a
  stack column. Fingerprints for existing images are made the first time you open *Similar images*.
