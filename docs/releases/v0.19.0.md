# Kurator 0.19.0 – Desktop app, right-click menu, Open with

## Highlights

### The desktop app
Kurator in its own window instead of a browser tab - optional; the browser works as before. The app
is a window for the Kurator you installed with `install.bat` / `install.sh`, not a second copy of it.
- **Starts and stops Kurator for you.** It finds your Kurator folder (or asks once and remembers
  it), starts Kurator in the background without a console window and stops it when you close the
  window - also if the app crashes or is ended, so no Kurator is left running. A Kurator already
  running from `kurator.bat` is used as it is and left running. While Kurator starts, a start page
  shows what is happening; if it doesn't start, the end of its log and a button to the log folder.
- **Drops with paths.** The app knows where dropped files are: files in the library are found by
  their path, new files are **copied from where they are** (nothing is uploaded), and **dropped
  folders can be added to the library**.
- **Drag files out** of the window into Photoshop, Krita, Blender, a folder or a chat: select
  thumbnails and drag them past the window's edge (Windows and macOS).
- **The system's right-click menu**, links in your default browser, downloads to Downloads, one
  window that comes to the front when you start the app again and remembers its size and place.
- **Installers** for Windows (`-setup.exe` for you only, no administrator; or `.msi`), macOS (one
  `.dmg` for Apple silicon and Intel) and Linux (`.AppImage`, `.deb`) are attached to this release.
  They are not signed yet: Windows SmartScreen asks once (*More info → Run anyway*), and macOS asks
  once (*System Settings → Privacy & Security → Open Anyway*). See [docs/desktop.md](../desktop.md).

### Right-click menu
In the browser and in the app:
- **Thumbnails:** Open, **Open with**, Show in Explorer / Finder, Copy path, Copy to…, Move to…,
  Send to a quick destination…, Rename…, Resample…, Delete… - for the right-clicked file, or for
  the selection when it is part of it.
- **Folders** (sidebar, path bar): Open, Show in Explorer / Finder, Copy path, Pin, **copy or move
  the selected files there**, add to or remove from the library.
- **Tags and projects:** show, narrow the view to it, hide its files, **add to or remove from the
  selected items**, edit.
- **The empty grid:** Select all, Invert selection. Text fields keep their usual menu.

### Open with
Krita, Photoshop, GIMP, Affinity, Pixelmator Pro, Aseprite, Paint.NET, Inkscape, Blender (`.blend`),
Audacity, REAPER and VLC are found where their installers put them and offered for the files they
open. *Open with → Programs…* (also ⚙ Settings → *Open with*) hides found ones and adds any other
program - its `.exe`, `.app` or command - for all files or only pictures, sounds, videos or 3D.

### Back and Forward
The mouse's back and forward buttons (and Alt+← / Alt+→) work in Kurator: **Back closes the
viewer**, then goes back through the folders, tags, projects and searches you visited; Forward
returns. Typing a search is one step, not one per letter. In the desktop app Back never leaves
Kurator (it used to show *cross-site request blocked*).

### The viewer's right-click menu
What fits the file you look at, then the file commands for that file only (Open, Open with, Show in
Explorer / Finder, Copy path, Copy to…, Move to…, Rename…, Resample…, Regenerate preview, Delete…):
- **Pictures:** *Copy colour #rrggbb* - the colour under the pointer -, fit / 100 %, background,
  pixel-art zoom, lit preview, inks; **SVG:** *Show what is outside the page* (for the session; the
  setting in ⚙ Settings stays the default); **PDF:** previous / next page.
- **3D models:** reset, shading, matcap, lights, cavity, smooth shading. A right-click that doesn't
  move the model opens it; right-drag still moves.
- **Video:** play / pause, 5 seconds back or on, **Save this frame as a picture** - a PNG next to
  the video, indexed, Ctrl+Z deletes it. **Sound:** play / pause, export the selection.

### Copy picture, Regenerate preview
- **Copy picture** (thumbnails and the viewer) puts the picture on the clipboard **full size** -
  from any kind of picture Kurator reads: PSD, EXR, Krita, SVG… - to paste into another program.
- **Regenerate preview** makes a file's thumbnails and previews again, for one file or a selection.

### 3D viewer: matcaps and cavity
Like Blender's solid view:
- **Matcap** - Clay, Studio grey, Red wax, Jade, Skin, Chrome, Toon; **M** goes through them.
- **Random colours** - one per part of the model; *Base colour (flat)* - unlit colours.
- **Cavity** (**C**) - ridges lighter, hollows darker, from the curvature at each vertex; works
  with every shading. Creases between parts count too.

### Drops land in the library
- New files dropped onto the **grid of a library folder go into that folder**. Otherwise into the
  folder used last in the project, else *Inbox* in your first library folder.
- A folder **outside the library** gets a ticked **Add this folder to the library**, so the files
  show, tagged. Before, they were copied there but Kurator didn't show them.
- **A tag or project shows all of its files**, also those in folders you only browsed (*Open…*) -
  its count already included them, the view didn't.

### Smaller changes
- While indexing, the status line names a file that takes long: *Indexing 0 / 348 · working on
  big.blend (2 min 10 s)* - big videos, models and layered files keep the count still for a while.
- Yes/no questions (remove a library folder, delete a tag, a backup set or a tag pool, empty
  Kurator's trash folder) are asked in the page instead of the browser's box - which the macOS app
  doesn't have.
- `--quit-on-stdin-close`: Kurator quits when its standard input closes (how the app runs it).

### CI
- The *Desktop app* workflow builds Windows, macOS (universal) and Linux on every change to the
  app, starts each build against the repository's Kurator (`--selftest`: the page loads and can use
  the app), keeps the installers as run artifacts and attaches them to published releases - after
  checking that the tag matches the app's version.
- macOS builds are signed and notarized once the Apple secrets are set (a Developer ID certificate
  made on Windows with OpenSSL, an App Store Connect key - [docs/desktop.md](../desktop.md#signing)),
  else signed ad hoc. Dependabot also watches the app's Rust and npm packages.

## Upgrading
- Update as usual and restart Kurator. Nothing new to install.
- For the desktop app, install it from this release; it finds the Kurator you already have.

## API
- `POST /api/drop/paths` `{paths}` – dropped files and folders by path: `files` (with catalog ids;
  library files not indexed yet get their row), `folders` (in the library or not), `skipped`.
- `POST /api/drop/copy` `{batch, dest, path}` – one dropped file copied into `dest`; finish with
  `POST /api/drop/done`.
- `POST /api/paths` `{ids}` – file paths. `POST /api/reveal-folder` `{path}`.
- `GET /api/apps`, `PUT /api/apps` `{custom: [{name, path, kinds}], hidden}`,
  `POST /api/open-with` `{app, ids}` – Open with; only listed programs start, by id.
- `GET /api/items/{id}/png` – the picture as PNG, full size (`?file=1`: written to Kurator's cache,
  `{path}` returned). `POST /api/remake` `{ids}` – make previews again.
- `GET /f/{id}?all=1|0` – an SVG with or without what lies beyond its page.
- `POST /api/roots` takes `create: true` (makes the folder first).
- `/api/items` with a tag or project: files in browsed folders too. The page `/` may be opened from
  another site (`Sec-Fetch-Mode: navigate`); everything else cross-site stays blocked.
