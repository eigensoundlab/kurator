# Kurator 0.19.1 – The desktop app installs Kurator, SFX Workbench link, Blender materials and renders

## Highlights

### The desktop app installs Kurator
No Python, Terminal or scripts needed any more: install the app, start it, click **Install Kurator**.
- The app downloads **its own Python** (3.14.10, a [python-build-standalone](https://github.com/astral-sh/python-build-standalone)
  build, checked against SHA-256 checksums built into the app) and **the Kurator code of its own
  version** from this repository, then runs Kurator's installer with that Python. The start page
  shows each step, with a progress bar for the downloads. About 80 MB, a few minutes.
- Everything goes into the app's own folder (`%LOCALAPPDATA%\com.eigensound.kurator`,
  `~/Library/Application Support/com.eigensound.kurator`, `~/.local/share/com.eigensound.kurator`).
  Your catalog and settings stay in Kurator's own data folder and are never touched.
- **Updates:** a newer app brings this Kurator up to its own version when it starts - seconds, as
  Python and the packages are kept. *Update now* in Kurator installs the newest release the same way.
- Already have Kurator from `install.bat` / `install.sh` or a clone? *Choose the Kurator folder…* -
  it works as before and keeps updating with its own scripts.
- The app now runs on **macOS 10.15** and newer (was 11).

### Installing never stops at one missing package
Some packages are compiled programs that are built for each Python and system. Right after a new
Python comes out, or on an older macOS, there may be no build yet - and pip then tried to compile one
and the whole install stopped with a long error (Python 3.15 on a Mac: *Failed building wheel for
pi-heif*).
- HEIC support (pi-heif) and PDF previews (pypdfium2) are now added **one package at a time,
  ready-made builds only**. When one is missing, Kurator is installed without it, and the end of the
  install says what is missing, why and how to get it:
  *HEIC / HEIF pictures: there is no ready-made pi-heif for Python 3.15 yet. To get it: install
  Python 3.14 too, then run ./install.sh fresh.* The add-ons (`3d`, `ai`) are added the same way.
- The installers choose the **newest Python that has builds for everything**: 3.14, 3.13, 3.12, 3.11
  before a newer one (on Windows `py -3.14` before `py -3`).
- `install.bat fresh` / `./install.sh fresh` rebuilds `.venv`, for example after installing
  another Python.
- **On a Mac, macOS fills in:** without pi-heif it decodes HEIC itself (`sips`); without pypdfium2
  (built for macOS 13 and newer) Quick Look makes the PDF and Illustrator previews, without
  page-by-page navigation.

### SFX Workbench: sounds out, results back
[SFX Workbench](https://eigensoundlab.github.io/SFXWorkbench/) is a web app for game sound effects.
- Right-click sounds → **Send to SFX Workbench…**: they open there, from any folder, tag or project.
- Everything you save in SFX Workbench - output, source, variations, slices, loops - comes back to
  Kurator **as new files**, never over another file: into the folder you choose (by default next to
  the first sound), tagged **SFX Workbench** (Source group) plus the open project and the view's
  tags, with the sound it was made from as its *source*. Kurator shows *From SFX Workbench: …*.
- On a folder, tag, project or the empty grid, **New sounds in SFX Workbench…** opens it empty, for
  generated sounds.
- **Private:** Kurator gives SFX Workbench a random key for those sounds and that folder only. It
  travels in the part of the address after `#`, which browsers never send to the web server. Only
  pages from SFX Workbench's address can use it. It ends a day after its last use; ⚙ Settings →
  *SFX Workbench* ends all links, and sets the address of your own copy.
- Chrome and Edge ask once whether SFX Workbench may *connect to apps on this device*: allow it.
  Firefox works too. Safari doesn't let web pages reach apps on the computer.
- Needs SFX Workbench with the Kurator link (in its changelog: *Kurator link*).

### Blender files: materials and renders
For `.blend` files in the 3D viewer, with Blender installed:
- **Materials** (button, or right-click): for each material, what feeds base colour, metallic,
  roughness, normal, emission, alpha… - an image texture (its size; **missing files** in red), a
  procedural node, or a value (a colour swatch) - and whether the 3D view shows it:
  - *in the preview*: an image texture;
  - *the preview shows the plain texture*: a texture through a Color Ramp or similar;
  - *not in the preview - bake it to a texture*: procedural nodes;
  - *missing file*.

  Also each mesh as exported (with its modifiers): triangles, vertices, **UV maps**, modifiers, and
  the scene's camera, lights and world. Read by Blender in a second or two, kept for next time.
- **◐ Render**: the file as Blender renders it - procedural materials, its lights and world - from
  its camera, or from a three-quarter view of everything visible (*From the file's camera* in the
  menu). **EEVEE** is quick and needs a graphics card (without one Cycles renders instead);
  **Cycles** (right-click → *Render in Blender*) is path traced and slower. Files without lights get
  a neutral studio on a clear background. The render shows in place of the 3D view - zoom, pick
  colours; Esc or *⟲ 3D* goes back - and *Save the render as a picture* puts a PNG next to the
  `.blend` (Ctrl+Z deletes it).

### Open with, in one piece
- Selected sounds → **REAPER: one track each** - a REAPER project with a track per sound, all
  starting at 0.
- Selected pictures → **Krita: as layers of one picture** (also GIMP and MyPaint) - an OpenRaster
  file with one layer per picture.

### Update notices
*⬆ Kurator 0.20.0* appears in the status bar when a newer version is out: what is new and how to
update. In the desktop app, **Update now** does it and starts Kurator again. Kurator asks GitHub once
a day; ⚙ Settings → *Updates* turns it off or checks now.

## Smaller changes
- The viewer stays on its file when the list reloads while it is open (after saving a video frame or
  a render, or when indexing finishes). Before, it could quietly switch to another file.
- The status line keeps refreshing even if painting it fails once, and catches up as soon as the
  window is back in view. Errors in the page go to Kurator's log (`[page] …`); the desktop app has
  developer tools (Ctrl+Shift+I).
- The installers accept `KURATOR_PYTHON`: the Python to use.

## CI
- The *Desktop app* workflow now also starts each build on a machine without Kurator: the app
  downloads its Python, installs this commit's Kurator (`KURATOR_SOURCE`) and shows it - on Windows,
  macOS and Linux, for every change.
- Release tags `v0.19.1`, `0.19.1` and `v.0.19.1` are all understood; *Run workflow* can attach the
  installers to an existing release.
- The tests install the `formats` extra (pi-heif, pypdfium2) through `dev`; pip-audit checks it too.

## Upgrading
- **Desktop app:** install this version from the Assets. With a Kurator you installed yourself,
  update it as usual (`update.bat` / `update.sh`); without one, click *Install Kurator*.
- **Scripts:** run `update.bat` / `update.sh`. If your `.venv` uses Python 3.15, install Python 3.14
  too and run `install.bat fresh` / `./install.sh fresh` to rebuild `.venv` with it (HEIC support;
  `install.sh` points this out).
- **SFX Workbench link:** update SFX Workbench too (it updates itself on the web; a copy of your own
  needs its newest version).

## API
- `POST /api/sfx/share` `{ids, dest, tags, label}` → `{url, files, dest}`: a link for SFX Workbench.
  `GET /api/sfx/links`, `DELETE /api/sfx/links` (end all).
- For SFX Workbench only (its origin, CORS; the token checked): `GET /api/sfx/link/{token}` (the
  sounds, the folder's name, the tags), `GET /api/sfx/link/{token}/file/{n}`,
  `POST /api/sfx/link/{token}/save?name=&src=` (a sound as the body; a new file, tagged, with its
  source).
- `/api/state`: `sfx` `{n, last, dest}` (what came from SFX Workbench since the start). Settings:
  `sfx_url`, and `sfx_default`, `sfx_links` to read.
- `GET /api/items/{id}/blend/report` - materials, meshes, scene of a `.blend`.
  `GET /api/items/{id}/blend/render?engine=eevee|cycles&camera=1|0` - a PNG; `X-Kurator-Engine`
  says which engine made it.
- `POST /api/open-with` answers with `layout` (`tracks`, `layers` or none); `GET /api/apps` lists
  each program's `layout`.
- `GET /api/update?force=1`, `POST /api/update/skip` `{version}`; its `app` is true for a Kurator
  the desktop app installed. `POST /api/client-log` - errors from the page, to Kurator's log
  (30 a minute).
