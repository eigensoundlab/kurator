# Kurator 0.16.0 – Playhead analysis of sounds (optional)

## Highlights

### A Playhead view of sounds
[Playhead](https://github.com/eigensoundlab/playhead) (Apache-2.0, same author) analyses a sound
into more than a waveform. Kurator 0.16 can show it.
- **Curves:** loudness, activity, arousal, harshness, tension, spectral surprise.
- **Events** with Schaeffer-style types.
- **Beats and sections** for music.
- **Descriptors from other fields:** impulsiveness (spectral kurtosis), time arrow, burstiness,
  decay and material class.

The method is described in: Sandner, D. (2026). *Playhead Beyond the Waveform: Cross-Field
Descriptors for Sound Design* [Preprint]. Zenodo. https://doi.org/10.5281/zenodo.24008128.

- **Optional and off by default:** ⚙ Settings → Sounds → *Playhead analysis (experimental)*.
  - It is a setting of the browser, because the analysis runs there.
  - While it is off, the style menu has no Playhead entry and nothing new is requested; Kurator
    behaves as before.
  - A saved *Playhead analysis* style falls back to *Peak + RMS* when it is switched off.
- **Playhead analysis** in the waveform's style menu, in the side panel and in the big viewer.
  - Playback, click-to-play, selection, hover and wheel zoom work as in the other styles.
  - The strip follows the zoom.
- **Look ▾** (shown with the Playhead view):
  - **Playhead's ready-made looks.** *Sound character* and *Hits and surprise* are for effects;
    *Structure*, *Rhythm* and *Music overview* are for music. Looks a sound can't use (music
    looks for an effect) are greyed out.
  - **Custom…** takes a look code, checked with `Playhead.parseLook()`, e.g.
    `wave,sections,lane:structureNovelty~signed,lane:localPulse,ticks:downbeats`.
  - The choice is remembered.
- **The legend** beside the strip is the one Playhead returns. **Tell us if this helps** opens
  Playhead's look-feedback form on GitHub with the current look code (`app=kurator`). It is only a
  link: nothing is sent from Kurator.
- **Side panel → Playhead:**
  - effects: events and their types, decay and material class, time arrow, burstiness;
  - music: tempo, the section letters (`ABACA`), loudness range;
  - a note when only the first 10 minutes were analysed, and a link *About Playhead analysis*.
  - Opening the panel never starts an analysis. *Analyse with Playhead* does, as does the
    Playhead view.
- The usual waveform styles stay the default. Kurator's own **playback cursor** (also called the
  playhead) is unchanged.

### How it works
- **Samples from Kurator:** `GET /api/audio/{id}/samples?rate=&mono=&max_seconds=`.
  - It returns little-endian float32, interleaved, with `X-Samplerate`, `X-Channels`, `X-Frames`
    and `X-Truncated`.
  - Decoding uses Kurator's own decoder, so every format it reads works, including AIFF and WMA
    (through ffmpeg), which browsers can't all decode.
  - At most 2 channels. `mono` averages them; `rate` decimates with a box filter.
  - Not gzipped (float audio hardly compresses).
- **Client policy:**
  - up to 2 minutes: the file's own rate, up to 2 channels;
  - longer: 22.05 kHz mono (10 minutes ≈ 53 MB instead of ≈ 210 MB);
  - only the first 10 minutes are analysed.
- **Analysis** in a module worker (`static/js/playhead-worker.js`), profile `auto`:
  - `sfx` up to 10 s, `music` above;
  - one job at a time; a newer request from the same view replaces its waiting one;
  - the sample arrays are transferred, not copied.
- **Documents are kept** in the data folder (`cache/playhead/`), keyed by the file's path,
  modification time and the Playhead version: `GET` / `PUT /api/audio/{id}/playhead?v=`.
  - Only documents with schema `playhead-analysis`, version 1, and the matching generator version
    are stored, at most 8 MB each.
  - A changed file or a new Playhead build analyses again.
- **Drawing only through `Playhead.drawStrip()`.** Kurator passes the size, the zoom range and a
  theme from its palette: blue for short sounds, orange for long ones, no red (that means
  clipping), and its own spectrogram colours for Playhead's spectrogram layer. It never fixes a
  look of its own, so a new Playhead build changes the look by replacing one file.

### The Playhead file
- `kurator/static/js/vendor/playhead-core.mjs`, Playhead **0.2.0**, unchanged.
  - SHA-256 `9ea143f955b200fb17a3e02069d7f288522045e076043a1dc0b2283fd461ab09`, the same as the
    0.2.0 build.
  - It was assembled from the `v0.2.0` tag exactly as `tools/build.js --dist` does. Running
    Playhead's build script wasn't allowed in the build environment, so the same joining step was
    done in Python, and the checksum confirms the result is identical.
- `vendor/README.md` has its source, version, checksum and how to update it. Playhead's NOTICE is
  in `vendor/PLAYHEAD-NOTICE`, and Kurator's `NOTICE` has a line for it.
- `.gitattributes` keeps git from changing the file's line endings, so the checksum stays valid on
  Windows.

### Measured here (sample sounds from `tools/make_v16_samples.py`)
- **A 2 s metal hit:** analysed in about 0.6 s, including reading the samples.
- **A 2.5 min piece at 120 BPM with sections A B A C A:** analysed at 22.05 kHz mono in 3.3 s.
  The result: music profile, 120.2 BPM, sections `ABACA`.
- **The same hit reversed, as AIFF:** decoded by Kurator; time arrow −9.8 (the hit: +9.8).

## Tests
- **`tests/test_playhead.py`:**
  - the samples endpoint: headers, byte length, values for a generated WAV, `mono`, `rate`,
    `max_seconds`, more than two channels, 415/404/422;
  - the document store: put and get; stale after the file changes or for another Playhead version;
    a wrong schema, version, path-like version or body over 8 MB is refused; requests without the
    app's Origin are refused.
- **`tools/ui_check_v16.py`** (browser):
  - off: no entry and no requests;
  - switching on in Settings;
  - a short sound, an AIFF and a long one in the viewer;
  - the canvas isn't blank, the wheel zoom redraws the strip, the cursor moves while playing;
  - the looks *Automatic*, *Sound character*, *Hits and surprise*, *Structure* and a custom code
    (a bad code is refused); the legend and the feedback link follow the look;
  - the panel section, with its *Analyse* button;
  - switching off falls back to *Peak + RMS*;
  - no console errors, apart from the 404 that answers "no stored analysis yet".

## Later
- **Library-wide analysis** with the `playhead` command-line tool from Playhead's releases.
  - The summaries and descriptors would be stored per file, for sorting and filtering
    ("impulsive", "metal-like decay", "harsh", "bursty").
  - REAPER markers would come from `playhead markers`.
- **Playhead mini-strips** as grid thumbnails, once a look for small sizes is chosen.
- **A small study,** with consent, of whether they help people find sounds.
- **Languages:** if Kurator gets translations, `Playhead.localize()` (Playhead 0.3.0) and the
  shared terms of `sound-vocabulary`.
