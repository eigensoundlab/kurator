# Kurator 0.8.0 – projects you work inside, and video

Projects become workspaces: open one and the whole app works inside it, across all your library
folders. Projects can also include things automatically. Videos join images, sounds and 3D models,
with their real recording dates.

## Highlights

### Projects as the top filter
- **Project switcher** (top left), or click a project in the sidebar: the grid, folder tree, tag
  counts and every filter now work **inside the project**. The folder tree shows only folders that
  hold project files. Click it again (or × in the path bar) to leave.
- **Two modes** in the path bar:
  - **In project:** only its files. **−** takes the selection out.
  - **Add from library:** the whole library, with project files marked ◆. **+** (or dragging onto the
    project) adds the selection.
- **Includes automatically** (*Edit…*), always up to date:
  - **Tags:** e.g. everything tagged *Creatures*, including sub-tags and future ones.
  - **Folders:** e.g. `D:\Game A\Concepts`, including new files.
  - **Other projects:** *Game A* can include *Game A – DLC*. Circular includes are prevented.
- Move rules and backup folders (`{project}`), backup scopes and *No project* count automatic
  members too.

### Video
- MP4, MOV, M4V, WebM, Ogg, MKV, AVI, WMV, FLV, MPEG, M2TS/MTS, TS, 3GP, MXF and VOB files are
  catalogued with their **recording date** (from the file, as phones and cameras store it), length,
  resolution, frame rate, codecs and bitrate.
- **Thumbnails** show a frame and the length. **Hover scrubbing:** move the mouse across a video in
  the grid to run through 8 frames of it.
- **Playback** in the viewer for MP4 (H.264), WebM, Ogg and most MOV files: Space pauses,
  Shift+← → jumps 5 seconds. Other formats open in your player with **O**.
- Previews use **ffmpeg** when it's installed (`winget install ffmpeg` on Windows). Without it,
  Windows still shows its own video thumbnails, and MP4/MOV files still get their length, size and
  recording date from Kurator's own reader.
- Big videos are read in chunks, never loaded into memory as a whole.

## Upgrading
- Unzip over your installation (or `git pull`) and run `update.bat` / `./update.sh`. The catalog
  is migrated automatically (new table for project sources); nothing is re-indexed.
- Existing projects keep working as before; automatic sources are optional.
- For video previews, install ffmpeg, restart Kurator and press *Rescan*.

## Notes
- **+ / −** add to or remove from the open project. Without an open project they still change the
  thumbnail size.
